# action-swiftlint

> [!IMPORTANT]
> **This action is retired and unmaintained.** It has not been updated since 2020 (SwiftLint 0.39.2 on Alpine 3.11). Do not use it in new workflows. This repository will be archived.

## Alternatives

- [norio-nomura/action-swiftlint](https://github.com/norio-nomura/action-swiftlint) — SwiftLint with GitHub annotations
- [cirruslabs/swiftlint-action](https://github.com/cirruslabs/swiftlint-action) — version-selectable SwiftLint with annotations
- On `macos-*` runners: `brew install swiftlint` (or Mint / a pinned release binary), then run `swiftlint` directly

## Historical description

Ran SwiftLint and reported findings on pull requests via [reviewdog](https://github.com/reviewdog/reviewdog).
